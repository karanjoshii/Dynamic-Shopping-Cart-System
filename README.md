🛒 Dynamic Shopping Cart System

A simple, modular, and efficient C++-based shopping cart system demonstrating the use of data structures, object-oriented programming, and basic inventory/cart operations.

📌 Overview

The Dynamic Shopping Cart System allows users to interact with a virtual cart—adding, removing, and viewing items—while showcasing structured code and clean logic flow. It is ideal for beginners learning data structures and OOP in C++.

🚀 Features

Add / Remove Items Dynamically – Manage cart items using efficient data structures.

Item Search & Display – View all items or check if an item exists in the cart.

Modular Code Structure – Multiple .cpp files for better readability and scalability.

▶️ How to Run

1️⃣ Clone the repository

git clone https://github.com/karanjoshii/Dynamic-Shopping-Cart-System.git


2️⃣ Navigate to the project folder

cd Dynamic-Shopping-Cart-System


3️⃣ Compile the program

g++ main.cpp items.cpp cart.cpp -o cart


4️⃣ Run the executable

./cart

📘 How It Works

User selects actions from a menu.

System processes input and updates the cart.

Operations are handled through classes such as Item and Cart.
